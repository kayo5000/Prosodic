# Sources

## Vox — *Earworm* (video series, transcripts)

Music-journalism explainers, generally well-researched, usually built
around one interviewed expert plus one measurable claim. Treated as
`reported` confidence by default — the reporting is careful, but it is
still journalism and not a paper.

## Standing note on transcripts as sources

Auto-generated transcripts mangle proper nouns and numbers. Any figure
pulled from one and used in code needs checking against the original
before it becomes a threshold. Figures recorded in `claims/` carry the
number as transcribed; that is a starting point, not a verified value.
